<h2>Girilen Prompt: </h2>
<h3>İngilizce (Yapay Zekalara Gönderilen Prompt)</h3>
<p>Write a Python program that shows a ball bouncing inside a rotating hexagon. The ball should be affected by gravity and friction and should realistically bounce off the rotating walls.</p>
<h3>Türkçesi: </h3>
<p>Dönen bir altıgenin içinde zıplayan bir topu gösteren bir Python programı yazın. Top, yerçekimi ve sürtünmeden etkilenmeli ve dönen duvarlardan gerçekçi bir şekilde sekmelidir.</p>
